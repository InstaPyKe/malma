Privacy & Data Protection Policy

Last Updated: September 2026 • MalmaTech protects client codebases, Android/web user data, and developer mentorship information.

01. Information We Collect

When you engage MalmaTech for full-stack web engineering, Android application development, or 1-on-1 developer tutoring, we collect only essential information:

  • Contact Details: Name, phone/WhatsApp number, and email address.
  • Project & App Specifications: Technical requirements, API credentials, Google Play / cloud deployment configurations, and brand assets.
  • Mentorship Records: Student learning tracks (Android or Full-Stack Web), project repositories, and session schedules.

02. How We Use Your Data

  • Designing, building, testing, and deploying your web platforms and Android mobile applications.
  • Configuring domain DNS, SSL certificates, cloud backends, and M-Pesa / Stripe payment gateways.
  • Delivering personalized 1-on-1 coding sessions, code reviews, and mentorship feedback.

03. Confidentiality & Code Ownership

All client source code, database schemas, Android `.aab`/`.apk` builds, and API keys are kept strictly confidential. Upon final project payment, 100% of intellectual property and custom source code rights transfer directly to you.
